# My Projects

Small practice programs in Python and JavaScript.

## Structure

```
python/
  number_guessing_game.py      # guess a number 1-20
  cyber-python-basics/         # 9 beginner security programs (see its README)
javascript/
  number-guessing-game.js      # same game in Node.js
```

## Run

```bash
# Python (3.8+)
python python/number_guessing_game.py
python python/cyber-python-basics/01_password_strength_checker.py

# JavaScript (Node 18+)
node javascript/number-guessing-game.js
```
